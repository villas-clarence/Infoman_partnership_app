# Infoman Partnership App

## 📘 Project Overview
The **Infoman Partnership App** is a web-based information management system developed to streamline the process of managing and monitoring partnerships between the university and external organizations.  

---

The system enables administrators to track partnership details, manage organization data, and ensure efficient communication between stakeholders.

---

## 👩‍💻 Developed By
**2nd Year DIT Students**  
**Polytechnic University of the Philippines – Taguig Campus**

---

## 🎯 Key Features
- 📂 Partner organization registration and record management  
- 🔍 Partnership tracking with status updates (Active, Pending, Completed)  
- 📑 Report generation and data visualization  
- 👥 Role-based access for administrators and users  
- 📧 Contact and feedback management system  
- 🔐 Secure login and session handling  

---

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server Environment:** XAMPP / Localhost  
- **Version Control:** Git & GitHub  
- **IDE:** Visual Studio Code
